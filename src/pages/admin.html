备份管理
导出当前所有数据为 JSON 文件，或从备份文件恢复。建议在重大操作前先导出一份全量备份。
设置备份：包含系统设置、商品、公益项目、商城开闭场、FAQ、公告正文及修订快照、版本信息等配置，不含逐用户公告确认、用户账户、账本、订单、日志和打卡记录。
设置备份包含表：system_settings、mall_products、charity_projects、mall_opening_schedule、content_faq、content_announcements、content_announcement_revisions、system_versions、admin_roles。
全量备份：包含全部核心业务数据，含用户、公告确认记录、余额、账本、订单、CDK、公益助力、打卡奖励记录、红包、反馈、系统日志、令牌等，文件较大。
全量备份包含表：users、accounts、bob_tokens、ledger、redeems、mall_order_listings、redeem_cdks、mall_products、charity_projects、charity_contributions、attendance_reward_records、mall_opening_schedule、red_packet_activity、red_packet_items、content_faq、content_announcements、content_announcement_revisions、content_announcement_acknowledgements、system_versions、user_feedback、user_feedback_messages、audit_logs、admin_roles、admin_user_roles、system_settings。
⚠️ 覆盖模式会先清空对应表再写入，用户余额和账本将被替换，操作不可逆，请谨慎使用。

群卡变量说明（点击插入）
{{title}}：原始标题文本（手动推送标题）
{{content}}：原始 Markdown 内容（手动推送内容）
{{open_time}}：商城开启时间（自动开启场景）

{{product_name}}：商品名称（库存/上新场景）
{{stock}}：库存文案（库存告急场景）
{{amount}}：价格文案（上新场景）
发送通道配置：这里控制群卡片发到哪个群、使用哪个模板以及投递方式；保存后立即生效，不需要重启服务。
选择预设群后会自动填入会话 ID；如果要发到其他钉钉群，请选择“自定义”。
用于指定群里发送的互动卡片模板，修改后下次发送立即生效。
群卡片投递时使用的操作人账号，一般填写可用的管理员或机器人绑定操作人。
开启后直接向整个群广播；关闭后只发送给下面填写的指定接收人。
仅在关闭“全员广播”时生效；留空时默认回退到操作人。
卡片模板里对应标题的变量名，通常和钉钉模板字段保持一致。
卡片模板里对应正文内容的变量名，支持 Markdown 内容。
可选项，用于群会话搜索或卡片检索时展示的小图标。
支持字段：text（按钮文字）、url（跳转链接，支持变量）、color（blue / gray / red）。留空则不显示按钮。
